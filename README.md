# Playwright Framework Using JavaScript

A minimal Playwright framework scaffold using JavaScript.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Install browsers:
   ```bash
   npm run install:browsers
   ```
3. Run tests:
   ```bash
   npm test
   ```

## Structure

- `config/` — configuration helpers
- `pages/` — page objects
- `utils/` — helper utilities
- `api/` — API clients
- `tests/` — Playwright tests
